# OpenFOAM Studio v5.1.0

**FOAMy, Claude and Codex now reason from the OpenFOAM installation that is
actually selected, with fresher evidence and stricter validation before they
change or run a case.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.1.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.1.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Installation-grounded AI

- The three AI surfaces share one efficient local knowledge layer instead of
  building redundant copies. Its identity includes the selected WSL distro,
  OpenFOAM version, resolved installation paths and installed-binary metadata.
- Switching distro or version, or changing an installation in place, invalidates
  the vocabulary, command catalogue, help and tutorial corpus together and
  rebuilds them in dependency order.
- Each AI panel shows the indexed OpenFOAM version, freshness, date, vocabulary
  size and tutorial coverage.

## More reliable actions

- Agent dictionary writes are checked against the installed vocabulary and the
  OpenFOAM parser before they reach the case. Known-invalid writes are refused.
- Guarded commands validate their option names and required values against the
  selected executable's own `-help` output before execution.
- OpenFOAM 9 and 10 no longer turn their reduced index into false claims that a
  runtime type does not exist when `foamToC` cannot verify it.
- FOAMy fingerprints the current case and reloads its bounded disk context after
  edits made by Claude, Codex, scripts or a terminal.

## Better retrieval, bounded context

- Tutorial retrieval now indexes both contents and paths, boosts exact OpenFOAM
  identifiers and retains the Italian CFD glossary. This fixes queries such as
  `snappyHexMesh` with `surfaceFeatureExtract` being displaced by generic mesh
  examples.
- The local corpus remains outside the model prompt. At most two excerpts and
  1,500 characters are attached, so the deeper index does not make ordinary
  conversations proportionally larger.
- New evaluation fixtures cover v9-v14 lookup behavior, command options,
  installation cache identity, Italian questions and exact identifiers.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. ParaView remains an
optional local integration. OpenFOAM and AI model weights are not bundled.
