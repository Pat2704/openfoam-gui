# OpenFOAM Studio v3.2.0

**The assistant launchers now share one movable control, and the Mesh viewer is
reliable across laptop displays and different graphics adapters.** Monitor and
File Editor refreshes are also more predictable during active work.

| | |
|---|---|
| **`OpenFOAMStudio-v3.2.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v3.2.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Assistant launcher

- FOAMy, Claude and Codex now sit in a compact stack at the bottom right and
  fan out when the pointer approaches.
- The whole circular fan can be dragged smoothly from the space between its
  buttons, and it starts directly at its saved bottom-right anchor.
- Open chat windows remain above the launcher. Opening or closing a chat
  collapses the stack, while a single remaining launcher stays fixed.

## Mesh viewer

- Camera framing accounts for both horizontal and vertical field of view, so
  the mesh remains centred on narrow laptop screens.
- The viewer remeasures after hidden layouts, resizing and WebGL context
  restoration, keeping the mesh and orientation axes visible.
- Drawing-buffer resolution adapts to device-pixel ratio and GPU limits without
  changing geometry or camera placement. WebGL2 creation retries without MSAA
  on adapters that cannot provide an antialiased context.

## Monitor and File Editor

- Manual Monitor refreshes can no longer be swallowed by automatic polling;
  the buttons spin until their requested update finishes.
- The File Editor tree updates automatically while visible, including expanded
  nested folders, without changing the open document, unsaved text, selection
  or expanded state.
- The word-wrap control now shows `Wrap On` or `Wrap Off`, with an active style
  and accessible pressed state.

## Upgrading

Replace the folder or portable `.exe`. Existing cases and assistant settings
remain on your machine.
