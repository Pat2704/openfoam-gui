# OpenFOAM Studio v5.8.0

**Group your cases in containers.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.8.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.8.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Containers

- A **container** is a folder of the run directory that holds cases and is not
  a case itself. Cases kept directly in the run directory work exactly as
  before, and the two can be mixed. Containers are one level deep.
- A folder is a container only because you said so: the app marks it with a
  small file, `.ofstudio-container`. Nothing is guessed from a folder's
  contents, and a folder without the mark is a case, as always.
- **Create** one from the Dashboard: type a name and press **Container**. The
  list shows each container as a row that opens and closes, with its cases
  under it.
- **Choose where a case goes** when you create it, clone it, copy a tutorial
  or make it in the New Case wizard: a menu beside the name lists the run
  folder and your containers.
- **Move a case** between containers, or back to the run folder, with its new
  **Move** button or by dragging it onto a container. The folder is moved as it
  is, with its results and logs.
- **Turn an existing folder into a container** from its rename dialog. The
  folders it already holds become its cases, after a confirmation that names
  them; nothing is moved or deleted. A case that has files of its own is not
  converted: move it into a container instead.
- A case in a container is named `container/case` everywhere: the File Editor,
  the terminal, Monitor, ParaView and the Claude and Codex agents.

## Safeguards

- A container cannot be used as a case, so "Delete case" can never remove
  every case inside one.
- A container is deleted, or turned back into a case, only when it is empty.
- Moving a case onto an existing name is refused, and a case that is open with
  unsaved changes asks first.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.7.0
functionality is included.
