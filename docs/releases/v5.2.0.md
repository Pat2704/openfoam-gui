# OpenFOAM Studio v5.2.0

**The window remembers whether you left it light or dark, and the built-in
agents no longer lose track of what they are allowed to do when you change
their mode mid-conversation.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.2.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.2.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## The theme survives a restart

- Light or dark is stored with the rest of the local configuration, not in the
  browser storage the app could never keep: the bundled server takes a new port
  at every launch, so the page origin — and everything saved against it — was
  new each time, and the app always reopened light.
- The saved choice is read before the first frame is drawn, so the window comes
  up in the right theme instead of correcting itself a moment later.

## Agents that describe themselves accurately

- Switching an agent between Guarded and No limits is now announced to it on a
  channel that belongs to the application, rather than as text prepended to your
  own message. An agent that is careful about prompt injection was right to
  distrust the old form, and one of them told a user their message looked like a
  manipulation attempt.
- Both agents are told that their instructions describe the mode in force *now*.
  Answers given under the previous mode were correct when they were given, and
  are no longer withdrawn as mistakes when the mode changes.
- In Guarded mode an agent now says which mode it is in and what No limits would
  allow, instead of calling a blocked action impossible — and it knows the
  Terminal in the Commands tab is your own shell, not subject to its limits.
- Codex receives the mode change too; previously only Claude did.

## Smaller things

- The OpenFOAM version buttons and ParaView's Auto-detect / Save path pair in
  the Dashboard settings are no longer crowded together.
- The README shows the Post-Process and ParaView tabs.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. ParaView remains an
optional local integration. OpenFOAM and AI model weights are not bundled.
