## OpenFOAM Studio v1.0.0

First portable Windows release of OpenFOAM Studio.

### Highlights

* 🖥️ GUI for OpenFOAM on Windows + WSL2
* 🔄 Support for OpenFOAM v9–v14
* 📁 Case management and dictionary editing
* ▶️ Simulation control and monitoring
* 🤖 FOAMy AI Copilot
* 📦 **Portable — no installation required**

### How to use

Download `OpenFOAM-Studio.exe`, place it anywhere on your PC, and run it.

**No Node.js, npm, Docker, or additional application installation is required.**

> **Requirements:** Windows 10/11 + WSL2 + an OpenFOAM installation.
