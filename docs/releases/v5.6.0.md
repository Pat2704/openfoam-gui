# OpenFOAM Studio v5.6.0

**Export the simulation as a video from the ParaView tab.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.6.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.6.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Video export

- A new **Video** tab in the ParaView workbench builds a timeline of views: set
  up a view in the viewport and use it until a chosen time step, change the view
  and add the next one, as many times as you like. Each view keeps a thumbnail
  and can be shown again, replaced with the current view or removed; between
  views choose a cut or a smooth camera move.
- **Speed**: every saved time step lasts a fixed time (slow motion, whatever the
  spacing of the results), or the video follows simulation time scaled by any
  factor (1 is real time). Fields between saved steps can be interpolated for a
  fluid result.
- **Output**: MP4 (H.264) or OGV, from 480p to 4K, 12 to 60 frames per second,
  with the colour range fixed as in each view or rescaled on every frame.
- The export uses the ParaView session already open, so the video shows exactly
  the pipeline on screen. It reports progress and time left, can be cancelled,
  and restores the view afterwards. Save the video anywhere, or into the case's
  `postProcessing/videos`.
- Before a long export the app renders a few frames of the case to measure the
  render time. Videos longer than 10 minutes, or expected to take more than 30
  minutes to render, ask first; only a video longer than one hour is refused.

## Feature Edges

- Displays in the ParaView workbench offer ParaView's **Feature Edges**
  representation (silhouette and sharp edges), with its line width. Each item
  lists the representations its own ParaView display supports, and video views
  keep them.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. MP4 uses the movie
writer included in Windows builds of ParaView (checked with ParaView 6.2.0); OGV
is offered where MP4 is not. All v5.5.0 functionality is included.
