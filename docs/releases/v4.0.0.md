# OpenFOAM Studio v4.0.0

**ParaView is now an integrated, app-controlled scientific visualization
workbench.** OpenFOAM Studio drives a real local ParaView process in the
background while keeping loading, filtering, rendering and interaction inside
the application.

| | |
|---|---|
| **`OpenFOAMStudio-v4.0.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v4.0.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Integrated ParaView workbench

- Open reconstructed and decomposed OpenFOAM cases, including cases generated
  with `paraFoam -touch`, without exposing the external ParaView interface.
- Select volume regions, boundary patches, groups, result fields, timesteps and
  standard ParaView representations.
- Build pipelines from a capability-detected catalogue of 23 filters, including
  Slice, Clip, Contour, Threshold, Stream Tracer, Glyph, Calculator, Gradient,
  sampling, geometry and temporal-analysis tools.
- Manipulate Slice and Clip planes, Stream Tracer seeds and Plot Over Line
  guides directly in the 3D viewport as well as through precise numeric fields.
- Open compatible STL, OBJ, PLY, VTK/XML, PVD, XDMF, EnSight, Exodus and CSV
  sources located safely inside the active case.
- Render at full viewport resolution with coalesced camera and timestep updates,
  including mesh-only cases without solver timesteps.

## Detection, reliability and display

- ParaView detection supports arbitrary versions and installation locations,
  with a manual folder or executable override for portable copies.
- Dashboard OpenFOAM and ParaView settings are now independent. OpenFOAM
  detection is faster and recovers from temporary WSL failures without losing
  a previously valid version list.
- The Mesh viewer keeps its HiDPI drawing buffer separate from its CSS geometry,
  preventing off-centre meshes and clipped orientation axes on scaled laptop
  displays.
- Active ParaView manipulator controls have clearer high-contrast states.

## Upgrading

Replace the folder or portable `.exe`. Existing cases, selected OpenFOAM
version and assistant settings remain on your machine.
