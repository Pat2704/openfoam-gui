What's new

Persistent FOAMy API key — your LLM provider config now survives restarts. It's stored locally and encrypted with Windows DPAPI (via Electron's safeStorage), tied to your user account — never bundled into the .exe.
Faster tab switching — tabs stay mounted instead of refetching everything from WSL on every click.
Fixed: residual plot showed nothing — a stray React.Fragment was hiding the chart's data series from Recharts. Curves now render correctly.
Monitor auto-refreshes its log list — new logs (e.g. from a running Allrun) show up without switching tabs and back.
One-click Allrun/Allclean — Allrun launches in the background and jumps you to the Monitor tab; Allclean now asks for confirmation.

Install: download OpenFOAMStudio-v1.2-portable.exe below, double-click. No installer, no Node.js, no Docker.

Requirements: Windows 10/11, WSL2 with Ubuntu, OpenFOAM v9–v14 installed inside WSL.
