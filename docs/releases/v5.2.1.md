# OpenFOAM Studio v5.2.1

**ParaView is found without being launched first, and opening a case says what
it is doing instead of spinning.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.2.1-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.2.1-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## ParaView is detected on a cold machine

- Detection used to validate every candidate by running `pvpython.exe
  --version`. On a machine that has not opened ParaView since the last reboot
  that call takes around a hundred seconds — against three once Windows has the
  files cached — and the check gave up after fifteen. Nothing was found until
  ParaView had been started once by hand, and a correctly pasted path was
  rejected along with everything else.
- The installation is now recognised by its layout: pvpython next to
  paraview.exe, the `share/paraview-*` folder, the version in the folder names.
  Nothing is executed, and auto-detection answers in milliseconds.
- A path you paste is the first thing consulted and the one that answers, so
  **Save path** accepts it instead of reporting that ParaView was found
  elsewhere. Quotes, `%VARIABLES%`, forward slashes, a trailing backslash, the
  `bin` folder, the install root, `paraview.exe` and a path one level too deep
  are all understood.
- Portable and unzipped installations are looked for in more places — the drive
  root, ProgramData, your profile, Desktop and Downloads — and a failed search
  is repeated on demand, so installing ParaView no longer needs an app restart.

## Opening a case reports its progress

- The ParaView tab shows the phase the engine is actually in — starting
  pvpython, loading the ParaView libraries, reading the mesh, preparing the
  first render — with the elapsed seconds beside it. The old four-step animation
  finished after five seconds and left a spinner behind, which is what made a
  slow first launch look like a hang.
- **Cancel** stops a start that is still loading, immediately, instead of
  waiting for the start it was meant to interrupt.
- Asking twice for the same case attaches to the engine already loading rather
  than queueing behind it and beginning again.
- Leaving the tab and coming back is no longer a repair step: the tab restarts a
  session that failed while it was hidden and re-requests a picture when the
  state arrived without one. Every request it makes now has a deadline.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. ParaView remains an
optional local integration. OpenFOAM and AI model weights are not bundled.
