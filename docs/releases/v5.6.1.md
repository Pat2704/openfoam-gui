# OpenFOAM Studio v5.6.1

**A focused fix for how Claude and Codex answers are displayed.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.6.1-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.6.1-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Claude and Codex replies

- A finished answer no longer repeats itself. Replies could show the same text
  several times over, each copy longer than the last, and list items could
  appear twice while the answer was streaming.
- When a turn completes, the panel now shows the provider's final answer once,
  replacing the streamed previews, while tool calls and reasoning stay in
  place. Codex now supplies its last completed message as that final answer,
  as Claude already did.
- The final answer is shown correctly as soon as the turn ends, without having
  to close and reopen the panel.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.6.0
functionality is included, including video export and Feature Edges in the
ParaView workbench.
