# OpenFOAM Studio v5.8.1

**The Monitor residual plot opens on the solver log.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.8.1-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.8.1-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Monitor

- **Show Chart** used to plot the first log of the case, which is usually
  `log.blockMesh`, and answer "No residuals found in log" for a case that had
  them. It now opens on the first log that contains residuals.
- **Refresh** on the residual plot re-reads the log whose curves are on
  screen, instead of going back to the first log of the list.
- The log menus show the plain log name. `foamRun` was labelled
  `foamRun (v13)` on every OpenFOAM version.

The residual values themselves were already right: checked on a v14 cavity
run, every Initial and Final value plotted in Monitor matches the solver log,
as in Post-Process.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.8.0
functionality is included.
