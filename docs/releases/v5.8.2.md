# OpenFOAM Studio v5.8.2

**Containers open closed, and OpenFOAM is found in /home or in a folder you choose.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.8.2-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.8.2-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Dashboard

- Containers start **closed**: the case list opens on the containers, and a
  container shows its cases when you click it.
- A container that receives a case (create, tutorial copy, clone, move)
  opens by itself, so the new case is in view. A renamed container keeps its
  open or closed state.

## Finding OpenFOAM

- The automatic search also looks in the **home folders** (and `/root`), up to
  three levels down, so a source build such as `~/OpenFOAM/OpenFOAM-12` is
  listed beside the `/opt` installations.
- OpenFOAM settings (the gear on the OpenFOAM card) have a new **Search
  folders** section: enter the Linux folder that holds an installation kept
  anywhere else, such as `/data/OpenFOAM`, and press **Search folder**. The
  folder is kept only if it exists and contains an OpenFOAM installation; it
  is remembered per WSL distro and searched every time. The **×** beside it
  stops searching it.
- Relative paths, `..`, `/`, the Windows drives under `/mnt` and the system
  folders `/proc`, `/sys`, `/dev` and `/run` are refused. The folder of the
  active installation cannot be removed until another version is selected.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.8.1
functionality is included.
