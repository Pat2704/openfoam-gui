# OpenFOAM Studio v5.9.3

**A new Etc tab browses the installation's `$FOAM_ETC` folder.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.9.3-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.9.3-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## The Etc tab

A new tab, just before Applications, opens the OpenFOAM installation's `etc`
folder: `bashrc`, the global configuration, the `caseDicts` and `templates`
that `foamGet` copies from, `thermoData` and the rest. It works like the
Applications and Src tabs: open folders, go back with the path at the top or
**Up**, and read any text file in the pane on the right.

The folder is taken from `$FOAM_ETC` in the selected installation's
environment, or `$WM_PROJECT_DIR/etc` when that is not set, so it follows
whichever OpenFOAM version is selected.

## Other changes

- **Tab shortcuts.** With eleven tabs, Ctrl+8 now opens Etc and Ctrl+9
  Applications; Src no longer has a digit shortcut.
- **Tab names.** They are shown from a 1180 px wide window (1120 px before), so
  the longer row still fits; narrower windows show the icons, with the name in
  the tooltip.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.9.2
functionality is included.
