# OpenFOAM Studio v5.9.2

**The File Editor reads `Allrun` and other shell scripts correctly: they are no longer coloured entirely as a comment.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.9.2-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.9.2-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Shell scripts in the File Editor

The editor read every file with OpenFOAM's dictionary rules. In the
`cd ${0%/*}` line that opens almost every `Allrun`, the `/*` was taken for the
start of a `/* … */` comment that never closed, so everything after it was
coloured as a comment.

Shell scripts are now read with the shell's rules. A file counts as a script
when it is named `Allrun`, `Allclean`, `Allmesh`, `Allrun.pre` and the like,
ends in `.sh`, or starts with `#!`. In a script:

- `#` starts a comment only where a word starts: `$#`, `${#var}`, `\#` and a
  `#` inside quotes are not comments;
- `//` and `/*` mean nothing;
- `'…'` and `"…"` are strings, and `$1` is not coloured as a number.

OpenFOAM dictionaries are coloured exactly as before.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.9.1
functionality is included.
