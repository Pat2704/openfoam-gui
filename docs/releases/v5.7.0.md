# OpenFOAM Studio v5.7.0

**Security fixes and supported runtimes: the app now runs on Electron 44 and
Node 22, and the Claude agent starts its replies sooner.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.7.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.7.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Security

- **File names can no longer run commands inside WSL.** A case file whose name
  contained `$(…)` or backticks had the command in its name executed when the
  file was read or written, including when the name came from a guarded Claude
  or Codex agent. WSL commands are now passed to bash unaltered, so such names
  are simply file names: they are created, opened, listed and deleted as
  written.
- Shell variables such as `$X` in commands typed in the Commands tab now behave
  as in a normal terminal.
- The app's local server refuses requests addressed to any host name other
  than `127.0.0.1` or `localhost`, which closes a DNS-rebinding route from a
  web page to the app.
- Next.js updated to 16.3.8.

## Runtimes

- The window now runs on **Electron 44** (Chromium 152), and the bundled server
  runs on **Node 22**. Both earlier versions no longer received security fixes.
- Settings and saved keys carry over unchanged, and the Mesh tab keeps
  hardware-accelerated 3D.
- The download is larger: about 121 MB for the portable file and 182 MB for
  the zip.

## Agents

- A new Claude conversation, or a change of model, effort, mode or case,
  starts replying in about one second instead of three to four.
- Codex is unchanged.

## Smaller fixes

- The residual axis labels its decades exactly (`1e-4` rather than a long
  decimal).

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.6.2
functionality is included.
