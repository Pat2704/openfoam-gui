# OpenFOAM Studio v5.9.4

**The File Editor stays fast on cases with many files, and remembers the file you had open in each case.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.9.4-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.9.4-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Faster on large cases

- **The file tree refresh.** The editor refreshes the case's file list every
  four seconds. Listing it started one extra process in WSL for every file, so
  on a case with about 1,400 files a refresh took 1.5 s. While it ran, the
  app's server answered nothing else, so opening a file or saving had to wait.
  The same listing now takes about 30 ms, and the editor's requests no longer
  hold up the rest of the app.
- **Typing.** The whole file tree was drawn again on every key pressed. With
  all the timestep folders of that case open, a keystroke took around 300 ms;
  the tree is now drawn only when it changes, and a keystroke takes around
  25 ms.

## Each case remembers where you were

Switching to another open case and back used to reset the File Editor: no file
open and the tree collapsed again. For as long as the app is open, each case
now keeps:

- the open file, reopened from disk so it is always current;
- the caret and scroll position in it;
- the folders you opened in the tree.

Unsaved edits are not kept: as before, switching case asks before discarding
them.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.9.3
functionality is included.
