# OpenFOAM Studio v3.1.0

**Codex is now a first-class OpenFOAM case agent.** It sits beside FOAMy and
Claude, uses the ChatGPT subscription you already have, and works only through
the same scoped OpenFOAM tools as the Claude agent.

| | |
|---|---|
| **`OpenFOAMStudio-v3.1.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v3.1.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Codex agent

- A new black ChatGPT-logo launcher opens a floating Codex panel above Claude.
- Sign in with a ChatGPT account, choose the available Codex model and reasoning
  level, then let it read, write and run your OpenFOAM cases.
- Codex has its own credential store, so signing in or out does not change the
  desktop Codex or CLI account already present on the machine.
- It receives only the app's OpenFOAM functions. Native filesystem, shell, web,
  skills, plugins and MCP servers are not inherited.
- Guarded and No limits modes match Claude exactly: every action remains visible
  in the conversation and the `/mnt/` protection stays in force.

## Interface

- The Codex panel now uses the recognizable ChatGPT blossom, a white/charcoal
  surface and ChatGPT-green controls.
- Each chat composer shows its own focus colour: green for Codex, orange for
  Claude and orange for FOAMy.

## Upgrading

Replace the folder or the portable `.exe`. Existing FOAMy, Claude and Codex
settings remain on your machine.
