# OpenFOAM Studio v5.9.1

**The app no longer leaves files behind in TEMP, and its browser cache no longer grows without end.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.9.1-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.9.1-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Housekeeping at every start

Earlier versions left files on disk that nothing ever removed. At every start
the app now removes what previous runs left behind:

- **Portable extractions** (about 350 MB each) left in `%TEMP%` when the
  portable `.exe` was ended before it could delete them: End Task, a crash,
  logging off or shutting Windows down with the app open.
- **ParaView session folders** (`openfoam-studio-paraview-session-*`), one of
  which was left at every launch.
- **Old Claude system-prompt files** in `%TEMP%\openfoam-studio-agent`.
- **Chromium's HTTP and code caches**, which only ever grew (hundreds of MB):
  their entries are tied to a port that changes at every launch, so none
  could be used again. Settings, sign-ins and Codex history are not touched.

The cleanup runs in the background and never delays the window. A folder whose
programs are still running, such as another copy of the app, is left alone.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.9.0
functionality is included.
