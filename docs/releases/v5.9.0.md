# OpenFOAM Studio v5.9.0

**One-click mesh and result analysis by the AI agents, and a File Editor with colours, folding and find/replace.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.9.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.9.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## AI agents (Claude and Codex)

- Two new buttons beside the shield: **Mesh** analyses the mesh of the open
  case (size, bounding box, patches, zones, decomposition, `checkMesh`
  quality), and **Results** analyses the run (log, time directories —
  `processor*` ones included when the case is decomposed — and
  `postProcessing/`). Neither changes the case.
- The conversation shows only a short label for these requests, and the
  answer comes in the language the conversation is in, or English when it is
  empty.
- Logs and fields can be hundreds of MB, so the agent no longer reads them
  whole: small scripts summarise them inside WSL into a few KB, whatever their
  size. Opening a file larger than 256 KB points the agent at these
  summaries instead.
- Tables in answers are drawn as tables, and lists no longer repeat lines.

## File Editor

- **Comments** and **numbers** in their own colours, and **indent guides**
  down every `{ … }` block. The palette button picks each colour — the
  theme's, a swatch or any — and the choice is remembered.
- **Find and replace** (Ctrl+F, Ctrl+H) with match case, whole word and
  regular expressions (`$1` is a group in the replacement); hits are
  highlighted in the text.
- **Folding**: a small arrow after every `{` folds its block, a folded block
  shows how many lines it hides and opens again on a click, and the toolbar
  folds or unfolds them all. Editing with blocks folded changes the file
  exactly where you see it.
- Files over 20 000 lines are shown plain, to keep typing fast.

## Also

- ParaView: changing the coloured variable no longer leaves the previous
  variable's legend on screen.
- In a window narrower than 1120 px the main tabs show their icons only, and
  the app no longer slides sideways.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.8.2
functionality is included.
