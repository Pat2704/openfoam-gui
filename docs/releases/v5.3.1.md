# OpenFOAM Studio v5.3.1

**Safer case operations, truthful mesh and Post-Process results, and a ParaView
session that cancels cleanly.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.3.1-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.3.1-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Cases, tutorials and editor

- Case creation, cloning and renaming now refuse collisions cleanly and remove
  partial copies after a failure. Timestep cleanup preserves the case's actual
  initial time, including cases that start before zero.
- Unsaved editor changes are protected when switching, closing or renaming a
  case. File reads, folder creation, batch deletion and clipboard operations
  report failures instead of presenting them as successful or empty results.
- Tutorial discovery follows the selected OpenFOAM installation through nested
  layouts and groups, while copy operations are atomic and installation changes
  cannot leave stale tutorial results on screen.
- The new-case wizard exposes only solver families for which it writes a
  runnable Foundation case, validates names earlier and waits for installation
  checks before claiming that the case is valid.

## Mesh results you can trust

- Boundary-condition validation distinguishes a missing mesh from a valid one,
  and patch parsing accepts the full OpenFOAM word syntax used by generated
  meshes.
- `checkMesh` now reads current Foundation output, including its final verdict,
  statistics, warnings and failures. An interrupted check is reported as a run
  failure rather than as a mesh-quality result.
- Surface extraction is asynchronous. Very large meshes are estimated before
  extraction and require confirmation instead of freezing the rest of the app.

## Post-Process data integrity

- CSV export reads the complete parsed table up to the documented safety caps,
  correctly quotes special characters and says when a limit was reached.
- Sampled profiles open the latest 200 snapshots and can still load a selected
  older time from a list of up to 20,000 entries. Truncated time and run lists
  are clearly marked.
- Dataset discovery, reads and logs reject symlink escapes from the case. Stale
  responses from a previous dataset, case or OpenFOAM installation are ignored.

## ParaView cancellation and accessibility

- Cancelling a start now invalidates in-progress discovery and queued starts,
  cleans temporary state and ignores late images or session responses.
- Camera and interaction requests have bounded timeouts. Pipeline items,
  visibility controls, ranges, toolbar actions and timestep controls expose
  keyboard and screen-reader labels.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. ParaView remains an
optional local integration. OpenFOAM and AI model weights are not bundled.
