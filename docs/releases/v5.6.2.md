# OpenFOAM Studio v5.6.2

**Correct solver residuals, usable chart export controls and easier ParaView numeric editing.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.6.2-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.6.2-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Residuals and chart export

- Monitor and Post-Process offer Initial and Final residuals. For each field
  and time step, Initial uses the first solve's labelled initial residual;
  Final uses the last solve's labelled final residual. Multiple pressure
  corrections no longer overwrite the first initial value. There is no
  Maximum option.
- Charts, tables, CSV and saved charts use the selected residual kind.
  Missing residuals remain gaps; later time-step blocks replace earlier rows
  when a log contains a restarted run.
- Hovering over a curve shows its actual variable name, including p and k,
  which could previously appear as Time.
- The chart export Size menu now opens visibly above the dialog. After
  resizing manually, selecting Standard restores 1600 × 900; other presets
  remain available too.

## ParaView and File Editor

- ParaView numeric property fields, XYZ components and video speed fields
  allow the entire value to be selected, cleared and replaced. Partial input,
  such as a minus sign or an exponent being typed, stays editable. Enter or
  leaving the field confirms a valid value; Escape restores the previous one.
  Valid zero values are preserved when properties load.
- ParaView reuses its prepared idle engine to open cases sooner, with
  cancellable warm-up and normal-priority case activation.
- File Editor shows the indexing spinner for the initial listing and a
  manual refresh. Background updates and lazy folder loading stay quiet.

## Compatibility and packaging

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. Existing functionality,
including video export and Feature Edges, is retained.

This release reuses the EXE/ZIP pair built from commit `7d23f73`, renamed under
the project's direct-publication policy. No rebuild or new test run was
performed for publication; the executable's embedded version remains 5.6.1.
Before publication, validation included 18 focused residual tests, comparison
of 20,000 initial/final values against the existing myCavity solver log, four
numeric-input tests, typecheck/lint and visible mouse interaction checks for
the size menu and ParaView numeric editing.
