# OpenFOAM Studio v2.1

**OpenFOAM Studio is now open source, under the MIT License.**

Nothing about how the app works has changed since v2.0 — this release exists to
put a license on it. Until now the project carried none, which in practice meant
all rights reserved: you could download it and use it, but nobody could legally
copy it, fork it or build on it. That is what MIT fixes.

| | |
|---|---|
| **`OpenFOAMStudio-v2.1.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. About a second to the window. |
| **`OpenFOAMStudio-v2.1.0-portable.exe`** | A single file, nothing to unzip — at the cost of about half a minute at every launch, because the portable format unpacks the whole app into TEMP each time. |

---

## What the license lets you do

Use it, change it, distribute it, and build a commercial product on it —
including a closed-source one. The single condition is that the copyright notice
and the license text travel with every copy you pass on.

`LICENSE.txt` now sits next to the executable in both downloads, along with
`THIRD-PARTY-NOTICES.md`. The second one is not a formality: OpenFOAM Studio
embeds Electron, Node.js, Next.js, React, three.js, Recharts and the Radix
components, all under MIT, ISC or Apache-2.0, and each of those licenses asks
that its notice reaches whoever receives the binary. That file is where they are.

## What has not changed

The app itself. The only visible difference is a copyright line in the footer.

**OpenFOAM is not part of this download** and never has been. It stays in your
WSL2 installation, where OpenFOAM Studio runs it as a separate program; the GUI
links nothing and ships no part of it, so OpenFOAM's own GPL is unaffected.
