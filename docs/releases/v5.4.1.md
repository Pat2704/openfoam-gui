# OpenFOAM Studio v5.4.1

**A focused reliability release for decomposed-case cleanup and Claude/Codex
conversations in both Guarded and No limits modes.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.4.1-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.4.1-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## File Editor: Clean TS for decomposed cases

- Clean TS now reads the complete timestep inventory used by Monitor, including
  times that exist only below `processor*/`, instead of relying on the visible
  top-level file tree.
- The initial time remains protected. Cleanup is refused while the case has a
  running process, backend errors no longer look like success, and the editor
  tree refreshes after deletion.

## Claude and Codex replies

- The transcript now recognises cumulative provider snapshots even when every
  snapshot has a different block ID. A growing reply is rendered once; when
  tool calls occur between snapshots, only the new suffix is added so the real
  event order remains visible.
- The shared prompt is provider-neutral and preserves its paragraph boundaries.
  Codex receives a durable `run_openfoam` description that remains accurate
  when the same conversation switches between Guarded and No limits. The app's
  server continues to enforce the selected mode independently of model output.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. This release contains
all v5.4.0 case-wizard functionality, including STL/OBJ import and the guided
`surfaceFeatures` and `snappyHexMesh` workflow for OpenFOAM 13 and 14.
