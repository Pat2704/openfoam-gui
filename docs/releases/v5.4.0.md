# OpenFOAM Studio v5.4.0

**A complete case-building guide for OpenFOAM 13 and 14, with safe geometry
import and a guided `surfaceFeatures`/`snappyHexMesh` workflow.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.4.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.4.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## From an STL to a checked OpenFOAM mesh

- **Import the real geometry.** New Case reads ASCII or binary STL and OBJ,
  including `.gz`, directly in the app. It finds the bounding box and named
  regions, proposes a background domain and an inside point, then uploads the
  original file to `constant/geometry` through a validated, case-local route.
- **Extract sharp features deliberately.** Each surface can enable a feature
  level. The wizard writes the compact `surfaceFeaturesDict` expected by the
  selected Foundation installation and runs `surfaceFeatures` before meshing;
  non-metre inputs are transformed first without altering the source file.
- **Guide `snappyHexMesh`, do not hide it.** The Mesh step follows the actual
  workflow: geometry and flow side, background box, surface and region
  refinement, `insidePoint`, snapping, layers and mesh-quality overrides. The
  generated dictionaries include OpenFOAM's installed `.cfg` defaults and
  write only the choices that differ from them.
- **Run the whole chain in order.** From the wizard: `surfaceTransformPoints`
  when needed, `surfaceFeatures`, `blockMesh`, `snappyHexMesh`, `checkMesh` and
  optional `setFields`. Logs remain visible, failed mesh checks are reported,
  and the finished mesh opens directly in the Mesh tab. Surface regions become
  patch groups so the generated initial fields follow the mesh names.

`snappyHexMesh` guidance is enabled only when OpenFOAM 13 or 14 exposes the
required configuration files; the ordinary `blockMesh` path remains the
default. Geometry names, sizes and paths are bounded and validated, and uploads
cannot escape the selected case through traversal or symlinks.

## A fuller New Case guide

- OpenFOAM 13 and 14 now expose guided physics for the installed solver
  modules: transient/steady controls, laminar/RAS/LES, thermophysics, species,
  phases, gravity, solid mechanics, initial regions, function objects and
  decomposition. Modules without a dedicated form start from a compatible
  installed tutorial whose fields are retargeted to the new mesh patches.
- Wizard-made cases carry a settings and file-hash record. **Update case**
  compares that record with disk, keeps hand edits by default and proposes
  re-meshing only when mesh inputs changed.

## Reliability fixes

- Deleting or renaming a case now clears its remembered New Case state, and the
  case-name focus ring no longer overlaps its label.
- Claude and Codex no longer render replayed response blocks and tool calls
  twice; provider block IDs update the existing transcript entry.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. Versions 9-12 keep the
shorter compatible case guide. ParaView remains optional; OpenFOAM and AI model
weights are not bundled.
