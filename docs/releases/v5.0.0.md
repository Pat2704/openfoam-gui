# OpenFOAM Studio v5.0.0

**A solved case now gives you its numbers, not just its picture.** The new
Post-Process tab reads everything OpenFOAM's function objects write, charts it,
and can produce it over timesteps that are already on disk — no ParaView
required.

| | |
|---|---|
| **`OpenFOAMStudio-v5.0.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.0.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Post-Process

- Reads `postProcessing/` and charts it: force coefficients, flow rates,
  pressure drops, y+, probe histories, sampled profiles. Beside each series it
  reports the last value, the mean over the final fifth, the min/max, and
  whether the quantity has settled or is still drifting.
- Time series are stitched across restarts, with a later run's recomputed rows
  replacing the older ones; sampled profiles keep one curve per written time and
  give you a time selector instead. Which of the two a dataset is comes from its
  own first column, not from a list of function names.
- Solver logs are listed beside the results and their initial residuals are
  charted the same way, so a convergence history can be read, compared and
  exported like any other dataset.
- **Follow** re-reads every few seconds, so a drag coefficient can be watched
  while the solver is still running.
- Copy any dataset as CSV.

## Computing new quantities

- **Compute…** lists the function objects this OpenFOAM ships — 127 on v14, 119
  on v13 — and runs the one you pick over the timesteps already written.
- Two editable texts, not a form: the whole command, flags included, and the
  `functions { #includeFunc … }` entry that runs the same thing during the
  solve. The entry is yours to copy; the app never edits your `controlDict`.
- Both are prefilled from the installation's own templates: real argument names,
  the examples each template documents, and a patch your case actually has.
- Underneath is what is particular to that one function — its arguments, the
  entries its configuration already sets and you can override, and the calls the
  installed tutorials actually make, each one click to load.
- An editable command is not a shell: it is parsed, and only `-func`, `-time`,
  `-fields`, `-region`, `-latestTime` and `-noZero` are accepted.

## Saving charts

- **Save chart** shows the picture before it is written, and the preview is the
  file: output size, background (white, dark, transparent or your own two
  colours), title, axis names, grid, legend, font size, line weight and a
  logarithmic axis.
- SVG stays sharp at any size and keeps its text selectable; PNG is rasterised
  from that same drawing at 1×, 2× or 3×.

## Fixes

- **An agent's file writes now appear immediately.** An edit made by Claude,
  Codex or FOAMy was invisible in the File Editor until the case was closed and
  reopened, because the editor's content cache was trusted without ever asking
  the file. It now watches the open file and refreshes a clean buffer in place,
  keeping the caret and scroll position. A buffer with unsaved edits is never
  overwritten — it is offered a reload instead.
- **Switching OpenFOAM version updates every tab.** The Post-Process catalogue
  kept describing the previous installation until the app was restarted, and a
  distro change raised no signal at all.
- **The Dashboard reports the solver and the mesh size correctly.** The solver
  was read only from the pre-v11 `application` key, so modern cases showed none;
  the cell count was looked for in a file that does not carry it and every case
  claimed a mesh of one cell. Patch names were never listed at all.
- The tab shortcuts are now `Ctrl+0`–`Ctrl+9`, in the order the tabs appear.

## Compatibility

Windows 10/11 with WSL2, OpenFOAM Foundation v9–v14 inside WSL. ParaView remains
an optional local integration. Nothing is installed and nothing is written to
the registry.
