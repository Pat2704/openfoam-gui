## OpenFOAM Studio v1.4

Download **`OpenFOAMStudio-v1.4-portable.exe`** below, put it anywhere and double-click it. Windows SmartScreen will warn on first run because the executable is unsigned: **More info → Run anyway**.

### New Case wizard — it now produces cases that actually run

The wizard wrote every case in the OpenFOAM ≤10 layout (`application simpleFoam;`, `transportProperties`, `turbulenceProperties`) and left `system/blockMeshDict` empty, so on OpenFOAM 11–14 nothing it produced could start.

- The case layout follows the **detected OpenFOAM version**: `solver <module>;` + `physicalProperties` / `momentumTransport` for 11+, the classic layout for 9/10. You can override the choice.
- The mesh step builds a **parametric box** and owns the patch list; every boundary condition in `0/` is generated against it, so the mesh and the fields cannot disagree.
- Choosing a RAS model adds `k` / `epsilon` / `omega` / `nut` automatically, with inlet values computed from the velocity, turbulence intensity and length scale.
- The summary step **preflights** the case (uncovered patches, missing fields, name already taken) and shows the commands to run next.
- Creating a case over an existing one now asks first, and a failed write is reported as a failure instead of a success.

Verified end to end: a generated case runs `blockMesh` + `foamRun` to completion on both OpenFOAM 13 and 14.

### FOAMy copilot — the context no longer lies

FOAMy answers with complete files, which is only safe if it has seen the complete file. It hadn't: case files were cut at 8 KB with no marker of any kind.

- Files carry their real size, and a shortened one is explicitly marked `TRUNCATED — first N of M bytes`. The system prompt forbids rewriting a file it has only seen part of.
- The case context has a size budget, and whatever does not fit is **listed** instead of silently dropped.
- A reply that hits the model's output limit is flagged, and its Apply buttons are withheld — a cut reply is a cut file.
- **Apply all** now runs the same shrink guard that single applies always did.
- Files you apply are sent back with the next message, so FOAMy stops reasoning about the version it saw at the start of the session.
- Replies now follow the language you write in.

### Mesh viewer

- **Vertex numbers keep a fixed on-screen size** at any zoom and on any model — they used to grow with the mesh until they covered it. Smaller, crisper pills.
- **Free rotation**: dragging no longer stops at the poles (TrackballControls, like ParaView's default camera).
- Turning the numbering on no longer resets your camera.

### File editor

- **Rename and move** files and folders: the pencil on any row of the tree, or the button in the editor header. Moving is the same operation as renaming; an existing destination is refused.

### Startup and stability

- The window now appears in **~0.2 s** with a splash instead of only once the local server answers; the server boots in parallel with Electron, and WSL is warmed up while the page loads.
- **A transient WSL hiccup no longer switches your OpenFOAM version.** The cached paths used to be discarded whenever a probe failed, so a cold start could silently re-detect a different install — with a different run directory, which made cases look like they had vanished. An explicit version choice is now remembered across restarts.
- Rebuilding the app no longer re-copies the whole standalone tree on every build.

### Known issue

Launching the portable `.exe` takes about half a minute before the window appears: the portable wrapper deletes and re-extracts the full application into TEMP on every launch. Everything above happens after that.
