# OpenFOAM Studio v5.5.0

**Case preflight in the File Editor, and a File Editor that fits the window.**

| | |
|---|---|
| **`OpenFOAMStudio-v5.5.0-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. |
| **`OpenFOAMStudio-v5.5.0-portable.exe`** | A single file, nothing to unzip. It extracts into TEMP on each launch. |

## Case preflight

- A read-only check of the open case against the selected OpenFOAM
  installation: core structure, run controls, decomposition, dictionary syntax
  through the installation's own `foamDictionary`, runtime-selection names and
  agreement between field boundary conditions and mesh patches.
- Findings are grouped as errors, warnings and explicitly unverified items,
  each with an explanation, a suggested action and a link to the file.
- It never copies the case, runs a solver, mesher or `checkMesh`, or executes
  `#codeStream`/`#calc`. Unsaved editor changes must be saved first, so the
  report always matches the case on disk.
- It starts from a green **Preflight** box beside Clean TS. Results open in a
  compact section under the editor that can be hidden to one line or closed and
  shown again without re-running; only **Run again** checks again.

## File Editor fits the window

- The editor fills its tab at any window size and follows resizes. The file
  tree and the open file always stay on screen and scroll inside their own
  panels; the page itself no longer scrolls.
- In short windows the new-file and new-folder inputs fold behind a **+**
  button and the status footer hides; in narrow windows Rename, Undo and Wrap
  become icons.

## Also

- The desktop window opens at up to 1600×1000 within the monitor's work area,
  and Commands gives the terminal all the space above Quick Commands by default
  (drag to set a height, double-click the handle to fit again).
- Preflight ignores the wizard's own `system/studioWizard.json`.

## Compatibility

Windows 10/11 with WSL2 and OpenFOAM Foundation v9-v14. All v5.4.1
functionality is included.
