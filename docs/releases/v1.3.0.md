New: Mesh tab

A 3D view of the case's boundary mesh, next to Monitor. Press Load mesh and the boundary patches are extracted and displayed:

Orbit, zoom and pan; drag the bar beneath the view to make it taller
Per-patch colour, with click-to-hide — useful on 2D cases where the empty/wedge patches cover everything
Wireframe, XYZ axes, and standard viewpoints (±X, ±Y, ±Z, isometric) — looking down an axis is the quick way to check a 2D case is actually flat
blockMeshDict vertex numbers drawn on the model, with convertToMeters/scale applied — read your block topology without leaving the app

Only the boundary surface is loaded, so it scales with surface area rather than cell count. For fields, slices and clipping, ParaView remains the right tool.

Moved

checkMesh and boundary-condition validation now live in the Mesh tab. Both describe the mesh, not the running solve.

Improved

Hardware acceleration is enabled. It had been switched off as a blanket fix for an old input-freeze bug whose real causes were found and fixed in v1.2; with it off, 3D fell back to software rendering.
The theme toggle now works correctly when Windows is set to dark — it was previously a no-op in that case, and mislabelled.
The viewer background follows light/dark.

Fixed

A hydration mismatch logged on every page load.
Invalid file paths returned "Internal error" instead of a proper validation message.

Install: download OpenFOAMStudio-v1.3-portable.exe below and double-click. No installer, no Node.js, no Docker.

Requirements: Windows 10/11, WSL2 with Ubuntu, OpenFOAM v9–v14 inside WSL.
