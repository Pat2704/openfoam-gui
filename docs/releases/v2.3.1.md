# OpenFOAM Studio v2.3.1

**The Claude agent answers questions instead of running things.** A one-change
release.

| | |
|---|---|
| **`OpenFOAMStudio-v2.3.1-folder.zip`** | **Recommended.** Unzip once, anywhere, then run `OpenFOAMStudio.exe` from the folder. About a second to the window. |
| **`OpenFOAMStudio-v2.3.1-portable.exe`** | A single file, nothing to unzip — at the cost of about half a minute at every launch, because the portable format unpacks the whole app into TEMP each time. |

---

## What was wrong

Asking the agent a plain question could set a solver going. "Is this case ready
to run?" would have it start `foamRun` to find out — which rewrites time
directories and can occupy the machine for hours, to answer something you only
wanted told.

The cause was an omission rather than a bad rule: the agent's instructions
described *what* its tools are and *what* the guard rails refuse, and said
nothing at all about *when* to run. So "is this case ready?" and "run this case"
arrived looking much the same.

## What it does now

Reading is free and it should read freely — that is how it answers from your
actual case instead of from memory. Running is different, and it is now
something it is *asked* to do:

- **A question gets an answer.** It reads what it needs and tells you. It will
  not run `blockMesh` to find out, start `foamRun` to see what happens, or run
  `checkMesh` "just to be sure".
- **If reading genuinely cannot settle it**, it says what it would run and why,
  and stops there. Offering is the answer; the decision stays yours.
- **An instruction to run is an imperative** — "run blockMesh", "mesh it", "start
  the solver" — in whatever language you write in. A message that could be read
  either way is treated as a question.
- **One go-ahead covers one run.** Being told to run `blockMesh` is not
  permission to then start the solver.

This applies in **both** modes. Unrestricted mode widens *what* may be run, not
*when*.

## Checked in both directions

Three real turns against a live installation, so the agent is not simply inert:

| | |
|---|---|
| *"is claude_test ready to run?"* (guarded) | **no command run** — it read the case, found a genuine problem in `0/p`, reported it and asked whether to fix it |
| *"run checkMesh and tell me the result"* (guarded) | **ran it**, exactly `checkMesh` and nothing else |
| *"how many cells, which patches?"* (unrestricted) | **no command run** — read two files and answered |

## Upgrading

Replace the folder or the .exe. Nothing to migrate.
